🌱 新入社員オンボーディングの流れ

入社初日から1ヶ月目までの標準業務手順書（A4印刷対応）

📅 フェーズ1｜1週目（導入・環境整備）

flowchart LR A["🏢 入社・受付"] --> B["💻 PC/アカウント設定"] B --> C["👥 チーム紹介"] C --> D["📘 ルール説明"]
  • 🏢 入社手続き、社員証・座席案内、就業規則の説明
  • 💻 PC、メール、社内システム、VPNなどの初期設定
  • 👥 配属部署メンバーへの紹介、メンター決定
  • 📘 勤怠・申請フロー・情報セキュリティルールの説明
初週は「業務を始められる状態を整える」ことを最優先とします。

📈 フェーズ2｜2週目（基礎業務習得）

flowchart LR A["📚 業務研修"] --> B["📝 手順確認"] B --> C["🤝 OJT開始"] C --> D["💬 振り返り"]
  • 📚 担当業務の基本研修、業務フローの理解
  • 📝 標準手順書・マニュアルを用いた実務確認
  • 🤝 先輩社員同席でOJTを開始
  • 💬 毎日5〜10分の振り返り面談を実施
2週目は「理解」から「実践」へ移行する重要フェーズです。

🚀 フェーズ3｜3〜4週目（実務定着・自走化）

flowchart LR A["🛠 単独業務開始"] --> B["📊 進捗確認"] B --> C["🎯 目標設定"] C --> D["📝 1ヶ月面談"]
  • 🛠 比較的軽い業務から単独対応を開始
  • 📊 上司・メンターによる進捗レビュー
  • 🎯 次月の習得目標、担当範囲の設定
  • 📝 1ヶ月目面談で課題と成長ポイントを整理
1ヶ月終了時点で、日常業務を一定レベルで自走できる状態を目指します。
